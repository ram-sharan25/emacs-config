#+TITLE: Keybindings
#+STARTUP: overview

Opened with =C-c o k=.  TAB folds a section, S-TAB cycles all, =M-g i= jumps
to a heading, =q= closes.  Source of truth: =modules/personal/keymaps.el=.

* C-x t  Treemacs
These four replace tab-bar's =C-x t t/1/f/d=; the rest of =C-x t= is still
tab-bar.
| t | toggle tree for this project | f | reveal current file |
| 1 | treemacs only window         | d | open a directory    |

* M-m  Legacy leader (temporary)
The old keys, kept while the =C-c= layout is learned.
| M-m a … | = C-c i (AI)          | M-m r f/i/F/c | roam find / insert / by ref / capture |
| M-m n … | = C-c i n (NotebookLM) | M-m r g/r     | roam graph / buffer                   |
| M-m t … | = C-c t (time/tools)  | M-m r e/a/t   | roam add ref / alias / tag            |
| M-m m … | = C-c m (multi-cursor) | M-m r s       | search brain                         |
| M-m g m | git message popup     | M-m r p/n/C   | paper / paper note / compile notes    |

* C-x o  Window actions (ace-window)
Press =C-x o=, then a window's letter to jump there, or an action key first
and then the target window's letter.
| m | swap with window      | x | delete window          |
| M | move window there     | o | delete other windows   |
| c | copy window there     | n | flip to last window    |
| j | pick buffer in window | u | switch buffer there    |
| e | run command there     | T | transpose frame        |
| v | split vertically      | b | split horizontally     |
| F | split fairly          | ? | show this list         |

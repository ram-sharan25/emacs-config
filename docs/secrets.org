#+TITLE: Secrets used by this Emacs config

Two files in this directory are encrypted and decrypted on load by EasyPG:

| File                      | Holds                                  |
|---------------------------+----------------------------------------|
| =secrets.el.gpg=            | API tokens and passwords read by init   |
| =gcal-calendars.el.gpg=     | the Google Calendar list for org-gcal   |

Both use GPG key =6BEE6200A001282B=. The key is in Bitwarden as the Secure Note
=Brain GPG key=; import it and set trust to ultimate before loading this config.
Pinentry on macOS: =brew install pinentry-mac= and put
=pinentry-program /opt/homebrew/bin/pinentry-mac= in =~/.gnupg/gpg-agent.conf=.

The notes repository encrypts its journal with the same key; its own setup is in
=~/Stillness/Brain/README.org=.
